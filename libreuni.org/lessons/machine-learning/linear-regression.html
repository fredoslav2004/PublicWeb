Linear Regression

Linear regression is a supervised learning algorithm used to model the relationship between a dependent variable yy and one or more independent variables XX. At its core, the model assumes that the relationship is approximately linear. Despite its simplicity, it remains one of the most powerful and widely used tools in a data scientist’s arsenal.

The Model Representation

The hypothesis function hθ(x)h_\theta(x) is defined as:

hθ(x)=θ0+θ1x1+θ2x2+⋯+θnxnh_\theta(x) = \theta_0 + \theta_1 x_1 + \theta_2 x_2 + \dots + \theta_n x_n

Here:

  • hθ(x)h_\theta(x) is the predicted output.
  • θ0\theta_0 is the intercept (or bias term).
  • θ1,…,θn\theta_1, \dots, \theta_n are the weights (parameters) for each feature.
  • x1,…,xnx_1, \dots, x_n are the input features.

Vectorization: The Power of Linear Algebra

In practice, we don’t handle these variables individually. Using vector notation, where θ=[θ0,θ1,…,θn]T\theta = [\theta_0, \theta_1, \dots, \theta_n]^T and x=[1,x1,…,xn]Tx = [1, x_1, \dots, x_n]^T:

hθ(x)=θTxh_\theta(x) = \theta^T x

Vectorization isn’t just a notation convenience; it’s computationally essential. Modern hardware (CPUs/GPUs) can perform matrix-vector multiplication much faster than iterative loops (FOR loops) thanks to Parallel Processing and SIMD (Single Instruction, Multiple Data).

The Cost Function: Ordinary Least Squares (OLS)

To find the optimal parameters θ\theta, we need to measure how well our model fits the data. The most common metric is the Mean Squared Error (MSE), also known as the L2L2 loss. The cost function J(θ)J(\theta) is defined as:

J(θ)=12m∑i=1m(hθ(x(i))−y(i))2J(\theta) = \frac{1}{2m} \sum_{i=1}^{m} (h_\theta(x^{(i)}) - y^{(i)})^2

Why “Squared” Error?

  1. Differentiability: The squared function is smooth and differentiable everywhere, making it ideal for gradient-based optimization.
  2. Sensitivity: Squaring the error penalizes larger deviations more heavily than absolute error (∣y−y^∣|y - \hat{y}|).
  3. Statistical Foundation: Under the assumption that errors are normally distributed, OLS is the Maximum Likelihood Estimator.

Optimization: Gradient Descent

Gradient descent is an iterative optimization algorithm used to minimize J(θ)J(\theta). Imagine standing on a hill in a thick fog; you can find the bottom by feeling the slope of the ground and walking in the direction that goes down.

The update rule for each parameter θj\theta_j is:

θj:=θj−α∂∂θjJ(θ)\theta_j := \theta_j - \alpha \frac{\partial}{\partial \theta_j} J(\theta)

Where α\alpha is the Learning Rate. Calculating the partial derivative gives:

θj:=θj−α1m∑i=1m(hθ(x(i))−y(i))xj(i)\theta_j := \theta_j - \alpha \frac{1}{m} \sum_{i=1}^{m} (h_\theta(x^{(i)}) - y^{(i)}) x_j^{(i)}

The Learning Rate (α\alpha)

  • Too Small: Convergence will be extremely slow.
  • Too Large: The algorithm can overshoot the minimum, potentially diverging or oscillating.

Advanced Case: The Normal Equation

For some linear regression problems, we can solve for θ\theta analytically. This is done by setting the derivative of J(θ)J(\theta) with respect to θ\theta equal to zero. The resulting formula is the Normal Equation:

θ=(XTX)−1XTy\theta = (X^T X)^{-1} X^T y

Evaluating Regression Models

Accuracy isn’t the right metric for regression because our predictions are continuous values. Instead, we use:

  1. Mean Squared Error (MSE): Average of squared residuals. 1m∑(y−y^)2\frac{1}{m}\sum(y-\hat{y})^2.
  2. Root Mean Squared Error (RMSE): Square root of MSE. It brings the error unit back to the scale of yy.
  3. Mean Absolute Error (MAE): Average of absolute residuals. More robust to outliers than MSE.
  4. R-Squared (R2R^2): The “Coefficient of Determination”. It measures the proportion of variance in yy explained by XX. Values range from 0 to 1.

Assumptions of Linear Regression

Linear regression is a parametric model, meaning it makes assumptions about the data:

  1. Linearity: The relationship between XX and yy must be linear.
  2. Independence: Observations should be independent of each other (no autocorrelation in time-series data).
  3. Homoscedasticity: The variance of the error terms (residuals) should be constant across all levels of XX.
  4. Normality of Residuals: For hypothesis testing (p-values), the errors should be normally distributed.

If these assumptions are violated, your model’s predictions and interpretability might suffer. In such cases, one might look toward Polynomial Regression or Generalized Linear Models (GLM).

Conclusion

Linear regression is more than just drawing a line through points. It’s an introduction to the core themes of machine learning: loss optimization, parameter estimation, and evaluation metrics. Mastering it prepares you for more complex models like Logistic Regression and Neural Networks.
