WEB2 Formula Sheet Reference

JavaScript Fundamentals Cheatsheet

1. Scope & Hoisting
var   = Function scoped. Hoisted. Can redeclare.
let   = Block scoped. Not redeclared. TDZ active.
const = Block scoped. Immutable reference. TDZ active.
2. Type Coercion Rules
Falsy values: false, 0, "", null, undefined, NaN.
Addition: string + anything = string (coerces to string).
Subtraction/Multiplication: "3" - 1 = 2 (coerces to number).
Equality: null == undefined (true). x === y checks type too.
3. "this" Context Resolution
Method call:    obj.method() -> this is obj
Simple call:    foo()        -> this is global/undefined
Arrow func:     () => {}     -> this is outer lexical context
Constructor:    new Foo()    -> this is new instance
Explicit bind:  foo.bind(x)  -> this is x
4. Array Higher-Order Functions
map:     [a].map(x => b)      -> [b] (transforms)
filter:  [a].filter(x => boolean) -> [a] (filters)
reduce:  [a].reduce((acc, x) => acc2, initial) -> value
forEach: [a].forEach(x => void)   -> void (side effects)
5. Asynchronous JS & Event Loop
Promises: States = [pending, fulfilled, rejected]
Microtasks (Promise.then, queueMicrotask) run before
Macrotasks (setTimeout, setInterval, I/O callbacks).
6. React Lifecycle & Rules
Hook Rules: Only call hooks at top level. Only call in React Components.
State updates: setState is asynchronous.
useEffect: [] (runs once on mount), [dep] (runs when dep changes).
7. TypeScript Structural Typing
TypeScript uses "duck typing". If object shapes match,
types match. Type guard using:
- typeof x === "string"
- x instanceof Foo
- "prop" in x
